# 重新实现清单

本清单记录工作范围，不把低文本相似度当成原创性或法律授权证明。

|责任|0.3.0 的处理|保留的兼容要求|
|---|---|---|
|任务契约与状态|domain 中新实现|公开类型、字段、严格输入、状态名称|
|调度与验收|application 中新实现|幂等、占位、目录互斥、同会话返工、证据摘要|
|任务与事件持久化|infrastructure 中新实现|原 SQLite 表和 JSON 内容、事件去重及事务|
|结果与成果验证|infrastructure 中新实现|结果格式、真实目录边界、完成/验收/下载摘要|
|HTTP 与工作台|transport 中新实现|本机端点、认证、状态查询、长轮询、SSE、成果下载|
|SDK 与 MCP|transport 中新实现|现有客户端调用和十个工具名称|
|WorkBuddy 连接及执行|infrastructure 中新实现|应用通信协议、收据、原生会话、worker 报告格式|
|CLI 与服务生命周期|runtime 和 cli 中新实现|serve/status/任务命令、设置、状态目录、连接形状|

行为依据是 [REIMPLEMENTATION-SPEC](REIMPLEMENTATION-SPEC.md)；旧平台路径作为兼容入口，不继续集中所有核心逻辑。各执行者被要求不得读取旧版借用模块或上游实现；历史研究思路与原生互操作协议仍在 [PROVENANCE](../PROVENANCE.md) 记录。

上述为 0.3.0 首次交付时的重写记录：构建和 71 项自动检查通过，独立审查 10 项复验通过，真实旧数据及两端原生状态读取通过；当时尚未执行新的桌面模型项目回归。原始监督端验收标准保持冻结，各模块另补测试。0.2.1 的三个项目验收仅为历史证据。
